ДЛЯ РАБОТЫ С ПРИЛОЖЕНИЕМ НЕОБХОДИМО ЗАРАНЕЕ СКАЧАТЬ ПРИМЕРЫ ЗАПИСЕЙ ЭКГ-СИГНАЛОВ ИЗ БАЗЫ ДАННЫХ MIT-BIH Noise Stress Test Database 

  

Программа - это кроссплатформенное десктопное приложение для загрузки, обработки, визуализации и анализа электрокардиосигналов (ЭКГ), разработанное на языке Python с графическим интерфейсом PyQt5. 

Основное назначение - предоставить исследователям и студентам удобный инструмент для сравнения трёх алгоритмов обнаружения QRS-комплексов (ключевых зубцов ЭКГ) на зашумлённых сигналах, а также для тестирования собственных алгоритмов благодаря механизму динамической загрузки пользовательского кода. 

Объём кода: более 600 строк. 

Технологический стек: Python 3, PyQt5, Matplotlib, NumPy, SciPy, scikit-learn, wfdb. 

  

Архитектура приложения построена на объектно-ориентированном подходе и разделена на несколько независимых компонентов, каждый из которых отвечает за свою область задач. 

  

В основе лежит абстрактный базовый класс QRSDetector. Он определяет общий интерфейс для всех алгоритмов детекции - в нём объявлен абстрактный метод detect(ecg_signal, fs), который должен принимать массив ЭКГ и частоту дискретизации, а возвращать список индексов найденных R-пиков. Также класс содержит абстрактные свойства name и description для идентификации алгоритма. Благодаря этому любой новый алгоритм можно подключить, просто унаследовавшись от этого класса и реализовав его методы, а главное приложение будет работать с ним через единый интерфейс. 

Главный класс QRSDetectorGUI наследуется от QMainWindow библиотеки PyQt5 и берёт на себя всю работу с пользовательским интерфейсом: построение и компоновку элементов управления, загрузку данных из файлов (CSV, TXT, WFDB), хранение сигналов и управление ими. Он же отвечает за применение фильтрации (ФВЧ, ФНЧ, режектор 50/60 Гц), наложение шумов (белый гауссовский или внешние загруженные шумы) с регулируемым уровнем, вызов выбранного алгоритма детекции, а также за визуализацию на графиках и навигацию по сигналу с помощью полосы прокрутки и клавиш. 

Отдельно реализован механизм динамической загрузки пользовательских алгоритмов. Он позволяет исследователю подключить собственный класс-наследник QRSDetector из внешнего Python-файла без перезапуска приложения. Для этого используется модуль importlib и динамическое создание модуля через types.ModuleType. При загрузке программа проверяет существование файла, корректность синтаксиса, наличие класса-наследника, а также предотвращает повторное добавление уже загруженных алгоритмов. В случае ошибки выводится понятное диагностическое сообщение. 

Для работы с шумами реализована библиотека, которая хранит загруженные пользователем шумовые сигналы в постоянном файле noise_library.pkl (сериализация через pickle). При запуске приложения библиотека автоматически подгружается. Пользователь может добавлять новые шумы из файлов (с проверкой совпадения длины с текущим ЭКГ), удалять ненужные, а также комбинировать несколько шумов одновременно с задаваемыми уровнями интенсивности. Это сделано через список с чекбоксами и слайдер общего уровня шума. 

Правая панель приложения содержит интерактивный холст на основе FigureCanvasQTAgg (интеграция Matplotlib в PyQt). На нём отображаются графики исходного сигнала, обработанного сигнала (с фильтрацией и шумами) и, при наличии шума, отдельный график с чистой шумовой компонентой. На обработанном сигнале красными кружками отмечаются обнаруженные QRS-комплексы. Под графиками расположена горизонтальная полоса прокрутки для перемещения по всей записи, а также информационная строка, показывающая имя файла, текущее смещение, длительность окна и количество найденных комплексов. Навигация также поддерживается клавишами-стрелками (влево/вправо) и колёсиком мыши. 

Все компоненты взаимодействуют через главный класс: например, при изменении параметров фильтрации или шума он пересчитывает обработанный сигнал, сбрасывает результаты детекции и обновляет графики. При выборе алгоритма из выпадающего списка обновляется текстовое описание, а при нажатии кнопки «Обнаружить QRS» вызывается метод detect() текущего детектора, после чего результаты отображаются на графике и в информационной строке.  

  

Интерфейс и возможности 

Приложение разделено на две панели: левая - управляющая, правая - визуализационная. 

  

Левая панель: 7 функциональных групп 

1. Загрузка данных 

Кнопка «Загрузить ЭКГ сигнал» - открывает диалог выбора файла. 

Поддерживаемые форматы: CSV, TXT, DAT, HEA (WFDB - формат PhysioNet). 

Для многоканальных записей WFDB программа предлагает выбрать номер канала через диалоговое окно. 

После загрузки автоматически выполняется центрирование сигнала и замена NaN. 

  

2. Алгоритмы обнаружения 

Выпадающий список с названиями трёх алгоритмов: Пан-Томпкинс, Корреляционный, Нейросетевой. 

При выборе алгоритма ниже отображается его текстовое описание с пояснением этапов работы. 

Сюда же автоматически добавляются успешно загруженные пользовательские алгоритмы. 

  

3. Параметры 

Частота дискретизации (Гц) - выпадающий список или поле ввода для корректной обработки сигнала. 

Окно отображения (с) - выбор длительности видимого фрагмента сигнала на графиках (от 1 до 1000 секунд). 

  

4. Фильтрация сигнала 

Включить/выключить фильтрацию (галочка). 

ФВЧ (Гц) - частота среза фильтра верхних частот (настраивается от 0.1 до 10 Гц). 

ФНЧ (Гц) - частота среза фильтра нижних частот (настраивается от 10 до 150 Гц). 

Режекторный фильтр - выбор подавления 50 или 60 Гц (или отключение) для устранения сетевой наводки. 

При любом изменении параметров обработанный сигнал пересчитывается автоматически, а результаты детекции сбрасываются. 

  

5. Добавление шума 

Слайдер уровня шума - регулирует интенсивность шума от 0 до 100%. 

Белый гауссовский шум - галочка для добавления нормально распределённого шума. 

Список сохранённых шумов - отображает названия ранее загруженных шумовых сигналов, каждый можно отметить галочкой. 

Кнопка «Загрузить и сохранить шум» - позволяет загрузить из файла собственный шум, задать ему имя и сохранить в библиотеку. Длина шума должна совпадать с длиной текущего сигнала. 

Кнопка «Удалить выбранные шумы» - удаляет отмеченные шумы из библиотеки. 

Кнопка «Применить выбранные шумы» - формирует результирующий сигнал как сумму текущего ЭКГ и выбранных шумов с учётом уровня. 

Кнопка «Сбросить шум» - обнуляет все шумовые наложения. 

  

6. Управление 

Кнопка «Обнаружить QRS» - запускает выбранный алгоритм на текущем сигнале. Во время выполнения курсор меняется на индикатор ожидания. 

Кнопка «Очистить результаты» - удаляет разметку QRS-комплексов с графиков. 

  

7. Добавление пользовательского алгоритма 

Поле ввода пути - вручную указывается путь к Python-файлу. 

Кнопка «Обзор» - открывает диалог выбора файла с фильтром *.py. 

Кнопка «Загрузить алгоритм» - выполняет импорт модуля, ищет класс-наследник QRSDetector, инстанцирует его и добавляет в выпадающий список. При ошибках выводит понятное сообщение (файл не найден, синтаксическая ошибка, нет класса-наследника). 

  

Правая панель: визуализация и навигация 

Область графиков (на базе FigureCanvasQTAgg). В зависимости от наличия шума строится от 1 до 3 графиков: 

График 1 (синий): исходный сигнал (нефильтрованный, без шума). 

График 2 (зелёный): обработанный сигнал (с учётом фильтрации и шума). На нём красными кружками отмечаются обнаруженные QRS-комплексы. 

График 3 (оранжевый): отображается только при активном шуме - показывает чистую шумовую компоненту. 

Горизонтальная полоса прокрутки позволяет перемещаться по всему сигналу. 

Управление стрелками - клавиши Влево/Вправо прокручивают график на 50% от ширины окна. 

Информационная строка - отображает имя загруженного файла, канал, длительность отображаемого окна, смещение и количество найденных QRS-комплексов. 

  

Подробнее о трёх алгоритмах детекции 

  

Алгоритм Пан-Томпкинса (классический) 

Суть: последовательная линейная и нелинейная обработка сигнала с адаптивными порогами. 

Этапы: 

Удаление дрейфа изолинии каскадом из двух медианных фильтров (окна 0.20×fs и 0.6×fs). 

Режекторный фильтр 50/60 Гц (если допустимо по частоте дискретизации). 

Полосовая фильтрация 5-18 Гц. 

Вычисление производной по пятиточечной формуле. 

Возведение производной в квадрат (нелинейное усиление). 

Скользящее интегрирование окном 150 мс (MWI). 

Адаптивное пороговое решение с двумя уровнями и поиском пропущенных комплексов (search-back). 

Уточнение положения R-зубца по широкополосному сигналу (3-35 Гц) в окрестности пика MWI. 

Результат: список индексов найденных R-пиков. Ошибка ≤3% на всех тестовых шумах. 

  

Корреляционный детектор 

Суть: измерение сходства между скользящим фрагментом сигнала и эталонным шаблоном с помощью нормированной взаимной корреляции (коэффициента Пирсона). 

Этапы: 

Полосовая фильтрация 3-30 Гц (для выделения частот, характерных для QRS). 

Формирование шаблона по первым 10 секундам записи: 

Поиск наиболее выраженных пиков. 

Вырезание фрагментов 200 мс вокруг пиков. 

Выравнивание фрагментов по кросс-корреляции. 

Усреднение выровненных фрагментов в единый шаблон. 

Расчёт коэффициента корреляции Пирсона между шаблоном и скользящим окном по всей записи. 

Поиск максимумов на корреляционной кривой с порогом 0.6 (при недостатке пиков порог снижается до 0.4). 

Уточнение положения R-зубца по абсолютному максимуму в окне ±50 мс вокруг пика корреляции. 

Результат: список индексов. Показывает высокую точность на мышечном шуме, но чувствителен к изменению формы комплексов. 

Нейросетевой детектор (MLP) 

Суть: многослойный персептрон (MLP) с 30 числовыми признаками, который классифицирует центр окна как «QRS» или «не QRS». 

  

Архитектура MLP: 

Входной слой: 30 признаков. 

Скрытый слой 1: 72 нейрона (ReLU). 

Скрытый слой 2: 36 нейронов (ReLU). 

Выходной слой: 1 нейрон (сигмоида, вероятность принадлежности классу QRS). 

Особенности реализации: 

Обучение «на лету» - если модель и скалер не найдены, при первом запуске автоматически обучается на синтетических данных. 

Синтетические данные - генератор создаёт 85 записей длительностью 20 секунд с реалистичными P-QRS-T-зубцами и варьируемыми параметрами: частота сердечных сокращений (36-165 уд/мин), амплитуда (0.45-2.4), ширина QRS (35-130 мс), полярность. 

Шумы в обучающей выборке: дрейф изолинии, сетевая наводка 50 Гц, белый гауссовский шум, мышечный шум (18-90 Гц), импульсные артефакты. 

Положительные примеры: окна, центры которых находятся в пределах ±10 отсчётов от истинного R-пика. 

Отрицательные примеры: окна вне защитной зоны шириной 340 мс вокруг любого истинного QRS. 

Валидация на реальных данных MIT-BIH - модель тестировалась на 5 типах шумов при SNR от 1 до 10. Ошибка детекции <2% на большинстве шумов. 

Кэширование результатов - для ускорения повторных запусков на одном и том же сигнале. 

Извлечение 30 признаков для каждого окна: 

Базовые статистики (мин, макс, среднее, СКО, медиана, MAD). 

Энергетические соотношения центральной зоны и фона. 

Параметры первой и второй производных. 

Спектральные доли в полосах 2-8, 8-18, 18-45 Гц и выше 45 Гц. 

Смещение глобального максимума модуля от центра окна. 

Результат: список индексов R-пиков. Наиболее устойчивый алгоритм на комбинированных шумах. 

  

После выполнения любого алгоритма программа: 

Отображает обработанный сигнал с наложенными шумами и фильтрацией. 

Отмечает обнаруженные QRS-комплексы красными кружками. 

В информационной строке показывает количество найденных комплексов. 

Если был применён шум, появляется третий график, где видна чистая шумовая компонента.
